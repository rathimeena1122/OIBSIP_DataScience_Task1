# 🌸 Iris Flower Classification using Machine Learning

## 📌 Objective
To develop a machine learning model that classifies iris flowers into different species based on their features.

## 🛠 Tools & Technologies
- Python
- Pandas
- Seaborn
- Matplotlib
- Scikit-learn

## 📂 Dataset
The dataset contains measurements of iris flowers such as:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The target variable includes three species:
- Setosa
- Versicolor
- Virginica

## 🔍 Steps Performed
1. Loaded the dataset using pandas  
2. Performed data exploration (EDA)  
3. Checked for missing values  
4. Visualized data using seaborn graphs  
5. Split the dataset into training and testing sets  
6. Trained the model using K-Nearest Neighbors (KNN) / Logistic Regression  
7. Evaluated the model using accuracy score  

## 🤖 Model Used
- K-Nearest Neighbors (KNN)  
- Logistic Regression  

## 📊 Outcome
The model successfully classified iris flowers into their respective species with high accuracy.

## 🚀 Conclusion
This project helped in understanding classification techniques, data visualization, and model evaluation in machine learning.
